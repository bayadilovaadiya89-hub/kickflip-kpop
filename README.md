## ⚡ Features
- 🛹 **7 Member Profiles**: In-depth stats, birthdays, MBTI, trainee journey, and signature skate tricks for Kyehoon, Amaru, Donghwa, Juwang, Minje, Keiju, and Donghyeon.
- 🎵 **Interactive Web Audio Boombox**: Preview synthetic 808 hip-hop beats for the debut mini-album *Flip it, Kick it!* (*Mama Said*, *WARRIORS*, *Knock Knock*, *Like A Monster*).
- 🎯 **Interactive Bias Quiz**: "Who is your KickFlip Soulmate?" with confetti celebrations!
- 🎬 **Video Vault**: Official MVs, skate sessions, and choreography showcases.
- 💬 **WeFlip Fan Wall**: Leave love and cheers for KickFlip (persisted via `localStorage`).
- 🔊 **Sound Effects Engine**: Skate pop audio feedback on interaction.
- 🖱️ **Dynamic Skate Cursor**: Custom interactive trailing cursor.

---

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite 8
- **Audio Synthesis**: Web Audio API
- **Icons**: Lucide React
- **Animations**: CSS Keyframes + Canvas-Confetti
- **Deployment**: GitHub Pages (via GitHub Actions & `gh-pages`)
